# 🎯 2. Guess the Number Game

**Guess the Number** is an interactive console game where the computer generates a random number and the player tries to identify the correct number.

The program compares the player's guess with the generated number and provides feedback until the correct number is found.

### Features

* Generates a random number
* Accepts guesses from the user
* Checks whether the guess is correct
* Provides feedback
* Repeats the game until the correct answer is found

### Concepts Used

* Random number generation
* `while` loop
* `if-elif-else`
* User input
* Comparison operators
* Logical thinking

This project helped me understand how loops and conditional statements can work together to create an interactive program.

# 💧🐍🔫 4. Water Snake Gun Game

The **Water Snake Gun Game** is a Python implementation of a simple two-player-style game where the user competes against the computer.

The computer randomly selects one of the three choices:

* 💧 Water
* 🐍 Snake
* 🔫 Gun

The program compares the player's choice with the computer's choice and determines the winner.

### Features

* Player vs Computer gameplay
* Random computer choice
* Automatic winner calculation
* Simple command-line interface
* Instant result

### Concepts Used

* `random` module
* Conditional statements
* Functions
* User input
* Comparison logic

This project was particularly useful for understanding how randomization and decision-making can be combined to create a game.
